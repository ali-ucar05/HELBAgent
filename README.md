# HELBAgent 🤖

HELBAgent is a web application developed with Python and Django that allows users to create, configure and interact with personalized AI agents.

Users can create an account, manage their profile, discover public AI agents and participate in shared chats where multiple users can interact with the same agent.

The application supports both local and API-based AI models and provides statistics to visualize user activity.

## Main Features

- User registration and authentication
- User profiles
- Creation and management of custom AI agents
- Custom prompts and agent avatars
- Local and API-based AI models
- Public AI agents
- Shared real-time conversations
- Configurable message cooldown
- User activity statistics and charts
- Message history
